# Simulación 3D del rover Perseverance

## Objetivo

Construir, paso a paso, una **simulación 3D del rover Perseverance** (NASA, Marte)
que pueda desarrollarse completa durante **una clase de 60 minutos**.

El proyecto es educativo: el código debe ser simple, legible y fácil de explicar
en voz alta. Se prefiere que algo funcione y se vea en pantalla rápido, y luego
mejorarlo por etapas, antes que una solución compleja o "perfecta".

## Qué debe tener la simulación

- **Terreno marciano**: suelo rojizo con algo de relieve y algunas rocas.
- **Modelo del rover** hecho con formas básicas: cuerpo, 6 ruedas, mástil con
  cámara y brazo robótico.
- **Movimiento**: el rover avanza, retrocede y gira con el teclado; las ruedas giran.
- **Cámara**: se puede orbitar alrededor del rover con el mouse.
- **Extras opcionales** (si sobra tiempo): helicóptero Ingenuity, polvo al
  moverse, cielo de Marte y datos en pantalla (velocidad, distancia recorrida).

## Plan de la clase (60 minutos)

| Minutos | Etapa |
|---------|-------|
| 0–5     | Introducción: qué es Perseverance y qué vamos a construir |
| 5–15    | Escena base: ventana, luz, cámara y terreno de Marte |
| 15–30   | Modelo del rover con formas simples |
| 30–45   | Control con teclado y animación de las ruedas |
| 45–55   | Rocas, cámara orbital y detalles visuales |
| 55–60   | Repaso, preguntas e ideas para seguir |

Cada etapa debe terminar con una versión que **funcione y se pueda mostrar**.

## Pautas para Claude

- Responder y comentar el código **en español**.
- Avanzar por etapas cortas, siguiendo el plan de la clase.
- Usar pocas dependencias y que sean fáciles de instalar.
- Explicar brevemente cada paso para que se pueda enseñar.
- Tecnología: por definir (Python con una librería 3D o web con Three.js).
  Consultar antes de elegir.
